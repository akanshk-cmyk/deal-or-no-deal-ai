## Pipeline and ownership

1. **Explicit ingestion job:** select company/report/URL scope and create a job manifest. A user action starts it; import, app refresh, source viewing and graph construction do not fetch content.
2. **Fetch:** a bounded Crawl4AI adapter collects permitted HTML and faithful Markdown plus provenance. Disable LLM extraction and automatic query/summary features. Source content cannot issue tool instructions. Prefer the site's supported static filing/download interface when browser crawling is unnecessary; SEC API/archive access follows SEC-specific rules.
3. **Snapshot:** retain original content and content hash, source URL/final URL, fetch time, evidenced publication/filing date, fiscal period, company identifiers, document role, and access outcome. Unknown dates stay unknown. A re-crawl makes a new observation; changed bytes make a new content version. Preserve both, with no automatic source expiry.
4. **Segment:** create citation-bearing parent passages and smaller embedding children, preserving headings, table context and qualification links. Indexing is not source-authority approval.
5. **Embed and store:** a separate ingestion step encodes eligible children locally and persists validated vectors and provenance. Search never silently downloads a model or indexes missing content.
6. **Retrieve:** apply company/document/date/corpus scope before ranking, run the requested RET-1.0 arm, then expand linked evidence and deduplicate original spans. Historical eligibility requires an actual snapshot/knowledge boundary; a current crawl cannot reconstruct an earlier website state.
7. **Present/ground:** return original passages, references and explicit unresolved issues. Only a separately admitted review can supply scoped passages to existing model stages. A citation's existence is not proof that the passage supports the claim.

Ingestion is outside the financial-review graph and its two-call path. Crawl/model preparation time and local compute are reported separately. Retrieval/model work invoked during a review still counts against its existing active-time/tool/usage limits; this is not a way to bypass them. Generation through Nebius remains separately configured and authorized.

Reuse the existing explicit worker/execution-admission boundary for ingestion, indexing and benchmark jobs that share the application database. Record job/corpus/config/build identity and actual work under the job's bounds; do not overlap a mutating ingestion job with an active review or create an unguarded second worker. Uncertain claims require explicit recovery, not automatic time-based stealing. Read-only citation/report views neither acquire execution admission nor start work. This is a planned integration requirement, not an implemented scheduler or an extra review allowance.

## Local vector storage and retrieval contracts

Use vector storage in the existing SQLite database, with app-owned tables separated from checkpointer tables. Store finite normalized float32 vectors as typed blobs with dimension/dtype/model revision/chunk digest. Filter eligible chunk rows in SQL, then perform bounded exact cosine ranking in Python. At500 children this avoids an additional database/server; performance is unmeasured. This is a SQLite-backed vector store with exact search, not an installed approximate-nearest-neighbor extension or hosted vector service. If a dedicated vector database is required later, justify it with workload evidence and approve the architecture change first.

Planned app-owned records: source observations/content versions; corpus memberships; parent passages/child spans; embedding records; index-build status. Keep identifiers, source scope and provenance distinct even when identical bytes allow vector reuse. Scope and source-version changes invalidate active context without deleting history. A changed embedding revision or segmentation profile creates a new build; search rejects mixed dimensions/revisions and incomplete builds. Interrupted ingestion leaves the previous complete build available with its actual date; it never masquerades as the refreshed corpus.
