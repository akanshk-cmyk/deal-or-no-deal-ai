# LIVE-GRAPH-1.0 - authorized live E-N01 integration

User requested completing live graph integration and evidence-review checkpoints.
Reuse build_graph, the existing SQLite database/admission/ledger, finance/policy/risk,
wire parsers, source-profile checks and seven-section pure-Python memo utilities.
No new dependency or automatic paid run. Existing saved-response behavior remains.

Start requires simulated Analyst scoped to registered E-N01, verified provider
contract and exact packet token-count evidence. Provider outputs are retained and
never replaced with registered responses. Changes to sources or live prompts stale
continuation. Credential loading remains explicit. Shared USD0.10 and existing
8,000/2,000 totals, correction reserve, attempts/nodes/tools/time limits persist.

After extraction, fact_review uses a real LangGraph interrupt before any calculation.
All present terms/financial fields require exact-target RiskManager evidence checks
and supporting source quotations; missing/conflicting values cannot be supported.
After synthesis, evidence_review interrupts on every observation, rationale,
condition and proposed-action reason. RiskManager reviews financial/risk meaning;
ComplianceOfficer reviews policy/control meaning; mixed targets require both.
Quotes and references are necessary but not semantic proof; only explicit scoped
review actions grant human support. Checks include meaning, numbers, units, period,
subject and qualifications. No prechecked boxes or universal support action.

Support commands are metadata only: exact request/target/domain/version, reason,
actor and UTC timestamp. They do not dispatch/resume or approve credit. Explicit
Analyst continuation revalidates and consumes current support on the persisted
checkpoint. Unsupported/withheld targets prevent continuation. Duplicate commands
never replay a provider call. Uncertain writes/dispatch keep recovery and allowance.

Only registered E-N01 source profile is admitted, not arbitrary uploads. Missing
financials stop before synthesis; unhandled policy/score escalation blocks completion.
Confidence-only normal review uses a separate AuthorizedApprover NORMAL decision
checkpoint. Conditional/exception handling remains the existing saved-case workflow;
a live exception is blocked, never waived by this bounded integration.

UI: explicit Live AI reviews selection in sidebar; start on New Deal, fact/claim
support and continue on Review Workspace, recorded stages on Agent Activity, pure
report on Credit Memo, scoped live event log on Decision History. Original citations
and both model responses are available; no real authentication/production claims.

Required checks: actual checkpoint pause/resume with mocked paid transport; changed
model extraction changes calculations; original response is retained; wrong role,
stale digest, missing quote/checks/domain and duplicate decisions fail safely;
missing data/no report; confidence review has separate credit decision; provider
error has no saved-answer fallback; unchanged default graph and total allowance.
Mocked transport proves integration only, not live model accuracy. Paid verification
remains blocked until access/current rates/whole-request fit are actually verified.

For this first live slice, all generated narrative targets are conservatively treated as potentially mixed-domain and require both Financial/Risk and Policy/Control support. A model-supplied panel label cannot reduce required human authority. This uses the approved roles and no additional model call or semantic classifier.

If a changed synthesis packet, missing key or provider setting needs verification, the synthesizer pauses through interrupt before any provider/node reservation. Persist the exact prepared packet and fingerprint. Explicit Analyst continuation rechecks configuration and the same packet before dispatch. Waiting for setup is not a technical failure and does not consume a model attempt.

Fact support uses the seven existing financial checks: reference, row label, value, units/scale, period, subject/facility and debt-service scope. Narrative support uses reference, value/claim, units/scale, period, subject/facility, qualifications and complete meaning. Reviewer checkboxes are explicit and empty by default. Credit decisions retain the NORMAL tier in their historical record.
