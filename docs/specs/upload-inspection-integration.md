# Uploaded package inspection — UPLOAD-1.0

Current extension: [single uploaded-deal live demo](upload-live-demo.md) supports
the exact complete Standard Deal package with new upload-derived Deal ID and
actual live analysis. The inspection contract below remains applicable to all
other packages; inspection alone does not authorize financial analysis.

User authorized the next recommended uploaded-document intake step. Reuse SPEC-001,
existing pypdf6.21.2, ignored var/ and the one SQLite/admission boundary. No provider,
new dependency, crawler, index, financial calculation or automatic case registration.

New Deal/Upload accepts an explicitly attested synthetic educational package:1–3
text PDFs, combined <=10,000,000 bytes and <=10 pages. Equality allowed. Analyst
only may submit; all five simulated roles may read the same local workspace upload
library. Library is separate from allowed financial deal records; upload metadata
does not grant access to, create, replace or resume any registered deal.

Validate basename/format/actual bytes, reject empty, encrypted, corrupt, zero-page,
any page without text, duplicate content and oversized packages. Isolate each parser
in a short-lived Python process under one45-second total parsing deadline. Stop on
more than120,000 extracted UTF-8 bytes; never truncate to fit. This is a time/text
bound, not an OS-level memory sandbox or general PDF-layout certification.

On explicit submit retain originals by content digest under scoped ignored var/uploads,
plus exact page text/hashes/locators and UTC observation. Use existing app_records
and global admission; no expiry/deletion. Invalid validation writes nothing. Reserve
execution before persistence; a partial filesystem/database gap becomes explicit
RECOVERY_REQUIRED and never auto-replays/deletes. Identical operation+input returns
the saved receipt; changed reuse conflicts. Read revalidates scope, retained bytes,
page hashes and package digest. Unknown dates/entity/period/authority stay unknown.

UI offers validation results, file/page source explorer and original PDF download.
Render text inertly. Source instructions are data. State INSPECTED_NOT_REVIEWED:
no score, policy clearance, AI recommendation or memo. No sample fixture fallback,
even for similar filenames. “Run review” stays unavailable for these unregistered
packages until scoped source/profile/fact/provider prerequisites exist. Viewing or
refreshing never parses, uploads, crawls or calls a provider.

Full-document page blocks support inspection/DIRECT provenance. Document-aware
semantic segmentation, verified tokenizer/embeddings, retrieval benchmarks, new-fact
admission and E-M01 continuation remain separate next work; page extraction is not
called token chunking or RAG. No financial or policy business rule is invented.

Acceptance: positive retained synthetic upload/reopen/citation/download; wrong role/
workspace, invalid format/encryption/no-text/pages/bytes/text, duplicate/stale operation,
changed retained source/text/path, parser timeout, partial persistence gap and no
financial/provider side effects. UI tests plus actual browser file upload where
available; synthetic fixtures only, never commit real financial documents.
