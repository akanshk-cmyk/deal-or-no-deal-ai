# Single uploaded deal live demo

Authorized by the user's instruction to implement one uploaded deal end to end.
Scope: one newly inspected complete Standard Deal PDF package, exact byte/page
match against its existing approved educational source profile. This is not
arbitrary-document onboarding. File names/order may differ; content may not.

Explicit Analyst Run AI Deal Review creates a distinct upload-derived Deal ID
and operation. Use retained uploaded page text as extraction context, existing
sample policy/scoring definitions only for this exact matched profile, actual
Nebius extraction and synthesis, existing LangGraph and shared USD0.10 allowance.
Never return saved extracted answers as live results. Historical samples stay
unchanged. A source map binds every logical citation to its uploaded file/page.

Keep the approved DEMO_DRAFT policy: technical integrity checks are not human
verification, mandatory readiness blockers prevent approval, and the memo is an
unverified educational draft. Existing HUMAN_REQUIRED reviews keep interrupts.
Only explicit Run/Continue can dispatch. Unsupported, partial, changed or mixed
packages remain inspection-only. No hidden retries, OCR, new dependencies,
database migration, RAGAS or general scoring assumptions.

All screens use the same context/scope Deal ID. Before execution, continuation
and source navigation, revalidate retained PDF hashes, parsed page hashes and
the profile. Duplicate Run retrieves the same operation. Viewing never calls.

Acceptance: mocked end-to-end upload/parser/live graph/shared UI; missing file,
wrong role/scope, replacement and duplicate tests; existing upload/live/saved
regressions; one actual bounded uploaded-package live run if provider validates.
